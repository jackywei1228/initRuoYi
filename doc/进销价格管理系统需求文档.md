# 进销价格管理系统需求文档

## 1. 文档概述

### 1.1 文档目的
本文档描述"进销价格管理系统"的功能需求，该系统基于现有 RuoYi-Vue 框架开发，用于管理产品采购成本和销售价格的完整业务链条。

### 1.2 业务背景
公司从供应商采购 Barebone（基础配置）产品，根据客户需求配置内存、硬盘、操作系统等配件，最终销售给经销商。需要一套系统来管理：
- 供应商信息和基础型号
- 可配置项（SPU/SKU 模型）
- 成本核算和价格计算
- 经销商分级价格体系

### 1.3 名词解释

| 名词 | 解释 |
|------|------|
| **Barebone** | 供应商提供的基础配置产品，包含 CPU、屏幕等核心部件 |
| **SPU** | Standard Product Unit，标准化产品单元，指基础型号 |
| **SKU** | Stock Keeping Unit，库存量单位，指具体配置方案（SPU + 配件组合） |
| **配件** | 可配置的组件，如内存、硬盘、OS 等，不同配件有不同的价格 |
| **DBP** | Distributor Buy Price，经销商采购价 |
| **RRP** | Recommended Retail Price，建议零售价 |
| **Build Margin** | 基于 DBP 的利润率 |
| **RRP Margin** | 基于 RRP 的利润率 |

## 3. 业务模型

### 3.1 核心业务关系

```
┌─────────────────┐                    ┌─────────────────┐
│   供应商         │                    │     配件库       │
│  (Supplier)     │                    │   (Accessory)   │
└────────┬────────┘                    └────────┬────────┘
         │ 1                                    │ n
         │                                      │
         │ n                                    │ n
┌────────▼────────┐      SPU 可关联配件      ┌──▼───────────┐
│   基础型号       │◄─────────────────────────►│  配件类型     │
│  (Barebone/SPU) │                           │ (内存/硬盘等) │
└────────┬────────┘                           └──────────────┘
         │ 1                                         │
         │                                           │ n
         │ n                                    ┌────▼───────────┐
┌────────▼────────┐                           │   配件规格值    │
│   SKU 配置方案   │◄────────── 选择配件 ──────│ (具体型号/价格) │
│  (SKU)          │                           └────────────────┘
└─────────────────┘
```

**业务流程说明**：
1. 供应商提供多个基础型号（SPU）
2. 每个基础型号可关联若干可配置的配件类型（如内存、硬盘、OS）
3. 为 SPU 选择具体配件规格后，形成 SKU
4. SKU 可关联不同价格方案

### 3.2 价格构成模型

```
供应商基础价 (USD)
    ↓
汇率换算 (USD → AUD)
    ↓
+ 配件加价 (内存/硬盘/OS 等)
+ Freight from China
+ Advertising
+ Build
+ Freight AU
+ Warranty
─────────────────────
= Total Cost (AUD)

Total Cost → DBP ex → Profit → RRP inc
    ↓              ↓           ↓
Build Margin              RRP Margin
```

### 3.3 SPU 与配件关联

每个 SPU（基础型号）可以关联多个可配置的配件类型：

```
SPU: Clevo V540KU1 / SCP4-C2-A5P
    │
    ├── 可配配件：内存 ✓
    │       ├── 8GB DDR4 3200MHz    +$40
    │       ├── 16GB DDR4 3200MHz   +$70
    │       └── 32GB DDR4 3200MHz   +$130
    │
    ├── 可配配件：硬盘 ✓
    │       ├── 256GB NVMe SSD      +$50
    │       ├── 512GB NVMe SSD      +$80
    │       └── 1TB NVMe SSD        +$120
    │
    └── 可配配件：OS ✓
            ├── Windows 11 Home     +$100
            └── Windows 11 Pro      +$150
```

选择配件组合后形成 SKU：
- SPU + 16GB内存 + 512GB硬盘 + Win11 Home = SKU-001
- SPU + 32GB内存 + 1TB硬盘 + Win11 Pro = SKU-002

## 6. 价格计算规则

### 6.1 计算公式

```java
// 1. 供应商基础价换算为 AUD
basePriceAud = supplierBasePriceUsd * exchangeRate

// 2. 配件加价总和
totalAccessoryAddUsd = Σ(选中配件规格的加价)
totalAccessoryAddAud = totalAccessoryAddUsd * exchangeRate

// 3. 总成本
totalCost = basePriceAud + totalAccessoryAddAud
          + freightFromChina + advertising + build + freightAU + warranty

// 4. Build Margin（基于 DBP 的利润率）
buildMargin = (dbpEx - totalCost) / dbpEx * 100

// 5. 利润
profit = dbpEx - totalCost

// 6. RRP Margin（基于 RRP 的利润率，DBP 考虑 10% 税）
rrpMargin = (rrpInc - dbpEx * 1.1) / rrpInc * 100
```

### 6.2 公式验证示例

根据用户提供的 Excel 数据：

**示例 1：Clevo V540KU1 / SCP4-C2-A5P**
- 供应商基础价：$475 USD
- 配置加价：$223.74 + $172.47 + $122.00 = $518.21 USD
- 汇率：0.63（USD/AUD）
- 附加费用：Freight $30 + Advertising $10 + Build $70 + Freight AU $10 + Warranty $10 = $130 AUD

计算：
- basePriceAud = 475 / 0.63 = $753.97 AUD
- totalConfigAddAud = 518.21 / 0.63 = $822.56 AUD
- totalCost = 753.97 + 822.56 + 130 = $1,706.53 AUD

（注：实际计算需根据系统具体实现调整）
